# Ciaren is running

The Ciaren editor opens in a new browser tab, with the Demo project loaded.
If your browser blocked the tab, use the link printed in the terminal below, or:

1. Open the **Ports** panel (bottom of the window).
2. Find **Ciaren editor** (port 8055).
3. Click the globe icon to open it in your browser.

The server log is in `/workspaces/.ciaren/data/ciaren.log`. To restart the server, run
`bash .devcontainer/ciaren.sh serve` in the terminal.
